# レザー製ULPキーキャップの作り方

## はじめに

このリポジトリはレザー製ULPキーキャップの3Dモデル（*.stl）とその使い方の本文書（README.md）から構成されます。
このリポジトリは、ULPの普及のため2026年11月時点で課題となっている、ULP打鍵感をレザーで何とかできないか、という目的のもと公開されています。

## 各ファイルの説明

### [commonフォルダ](./model/common/)

シリンドリカル、ホーミング共通で使用するモデルを格納しています。

- [hook.stl](./model/common/hook.stl) : キースイッチにキーキャプを固定する部分の3Dモデルです。
- [hook_alignment_guide.stl](./model/common/hook_alignment_guide.stl) : hook.stlをキーキャプに接着する際に使用する治具の3Dモデルです。
- [spatula.stl](model/common/spatula.stl)：キーキャップに接着剤をぬるヘラです。使用は任意
- [leather_ruler_guide_22mm.stl](model/common/leather_ruler_guide_22mm.stl)：革を22mmに裁断するための治具です。

### [cylindricalフォルダ](./model/cylindrical/)

シリンドリカル形状関係のモデルを格納しています。

- [cylindrical_cutting_guide.stl](./model/cylindrical/cylindrical_cutting_guide.stl) : 余ったレザーの切り取りのガイド部品です。
- [cylindrical_mold.stl](./model/cylindrical/cylindrical_mold.stl) : ウェットフォーミングに使用する凹部品です。
- [cylindrical_press.stl](./model/cylindrical/cylindrical_press.stl) : ウェットフォーミングに使用する凸部品です。

### [homingフォルダ](./model/homing/)

ホーミング形状関係のモデルを格納しています。

- [homing_cutting_guide.stl](./model/homing/homing_cutting_guide.stl) : 余ったレザーの切り取りのガイド部品です。
- [cylindrical_mold.stl](./model/homing/homing_mold.stl) : ウェットフォーミングに使用する凹部品です。
- [cylindrical_press.stl](./model/homing/homing_press.stl) : ウェットフォーミングに使用する凸部品です。

## その他必要なもの

- レザー
  - タンニン鞣しの厚さ1mmのレザーを用意してください。ハンズで売っているもので十分です。
- カッターナイフ
  - 革を裁断するのに使います。
- カッターマット
  - 革を裁断するときにデスクを守るのに使います。
- クランプ
  - 何でもいいです。私はダイソーのC型クランプを使ってます。
- 接着剤
  - レザーとフックパーツを接着するために使います。木工用ボンドでも良いですし、本格的なレザー用のボンドを用意しても構いません。瞬間接着剤はあまりお勧めしません。
- お湯をためられる容器
  - 革をお湯につけてぬらす工程で使います。ペットボトルの下の方切り取ったやつでもいいですし、そこらへんに転がっている容器を使ってください。

## 作成手順

いよいよ製作に入っていきます。

### 事前準備

1. 3Dプリンターで3Dモデルを印刷しておきます。hook_alignment_guide.stlとspatula.stlは任意ですがそれ以外はすべて必要なので忘れずに印刷しておいてください。フィラメントはマットなものがおすすめです。つやがあるものを使用すると革の表面がつぶれてつやつやになります。hook.stlは必要なキー数 x2 個必要です。
   - 印刷時の注意点
     - ノズル径は0.4mmで調整していますが、hook.stlは0.2mmの方がきれいに印刷できます。
     - hook.stlは非常に小さい 且つ 薄いパーツです。ビルドプレートからはスクレーパーなどで取り外すのをお勧めします。
     - クランプで圧縮するので、インフェルは100%で印刷してください。
     - つなぎ目は背面などに設定し、モデルの向きを調整して、革に触れる面につなぎ目が来ないようにしてください。
2. 革を22 x 22mmの正方形の形に裁断しておきます。
   - leather_ruler_guide_22mm.stlを使うと楽です。革の端を一直線に切断したら、この治具の少し立ち上がったところを革の断面にあてると、ちょうど22mmの幅に定規を当てることができます。

### ウェットフォーミング

別名「革絞り」といい、塗らした革を型で成形しながら乾燥させることで任意の形状にする技法です。ULPレザーキーキャップではキーキャップのほとんどが革でできているので、最も重要な工程といっても過言ではありません。

1. 容器に40度くらいのお湯をため、革を入れます。
   - お湯は清潔なものを使用してください。何日も置いておいた水を使うとカビが生えます。
    <div align="center">

    ![革に水分を浸透させている様子](img/IMG_7735.jpg)
    革に水分を浸透させている様子、革が沈んだら頃合い（沈まなくても十分に水がしみ込んでいればOK）
    </div>
2. 5～10分程度置いて革によく水がしみ込んだら、タオルなど吸水性が高いもので挟んで革の水気をよくとります。（平たいものを乗せて上から力を加えるといい感じになります。）
    <div align="center">

    ![キムワイプの上に乗せて](img/IMG_7736.jpg)
    キムワイプの上に乗せて

    ![上から押しつぶす！](img/IMG_7737.jpg)
    上から押しつぶす！
    </div>
3. 印刷しておいた、pressパーツを革の裏面、moldパーツが表面になるようにして挟み込み、pressパーツを押して、moldの中に革を押し込みます。
    <div align="center">

    ![大体真ん中にして](img/IMG_7738.jpg)
    大体真ん中にして

    ![指で押し込みます](img/IMG_7739.jpg)
    指で押し込みます
    </div>
4. pressパーツを指で押し込んである程度入ったら、クランプを使って奥までしっかり押し込みます。
    - ※動かなくなったなぁ、くらいで止めていいです。成人男性が限界まで締めると裏面のリブの模様が表面にくっきり出てしまいます。
    <div align="center">

    ![クランプで押し込んだ様子](img/IMG_7740.jpg)
    クランプで押し込んだ様子
    </div>
5. ここで一度moldから革を取り出します。この時とてもきついので、ペンチなどでpressパーツをつかんで引き抜くと上手く抜けます。
6. 圧縮されたことでにじみ出てきた水を乾いた布なのでふき取ります。
    <div align="center">

    ![革から余分な水分が出ている様子](img/IMG_7741.jpg)
    革から余分な水分が出ている様子、これを取っておくと乾燥が早いです。
    </div>
7. 水気をふき取ったら再度moldパーツに戻し、再度クランプで固定します。
8. この状態のまま2晩寝かせます。1日だと乾燥が甘く使っているうちに収縮し押し心地が悪くなってしまいます。

### 余った革の切り取り

1. 2晩乾燥させたらこんな感じになります。クランプで押しつぶすことで数ミリの立ち上がりがきれいに成形できているのが分かっていただけるはず。
    <div align="center">

    ![2晩乾燥させた様子](img/IMG_7749.jpg)
    2晩乾燥させた様子
    </div>
2. moldから取り外したらcutting_guideにはめてください。
    - ※ホーミングキーの場合はポッチの位置に気を付けてください。位置を間違えるとポッチが潰れます。
    <div align="center">

    ![切り取り用治具にはめた様子、moldを少し深めに設計している](img/IMG_7750.jpg)
    切り取り用治具にはめた様子、moldを少し深めに設計している
    </div>
3. cutting_guideのフチにカッターの刃を合わせながら、余った革を切り取ります。革をcutting_guideに残しながら、pressパーツを抜きます。
    <div align="center">

    ![切ったらこんな感じ](img/IMG_7751.jpg)
    切ったらこんな感じ
    </div>

### 固定パーツの接着

1. 固定パーツ（hook.stl）を治具（hook_alignment_guide.stl）に乗せておきます。
    <div align="center">

    ![これを、、、](img/IMG_7753.jpg)
    これを、、、

    ![こう！](img/IMG_7754.jpg)
    こう！
    </div>
2. ヘラ（spatula.stl）に少量の接着剤を乗せて、写真のようにリブの縦方向の側面に接着剤を塗布します。
    <div align="center">

    ![ここに接着剤を塗ります](img/IMG_7752.jpg)
    ここに接着剤を塗ります

    ![ちょい付けして](img/IMG_7755.jpg)
    ヘラにちょい付けして

    ![あてがいます](img/IMG_7756.jpg)
    あてがいます

    ![これくらい接着剤を残す感じで](img/IMG_7757.jpg)
    これくらい接着剤を残す感じで
    </div>
3. 治具を使って、接着剤を塗ったところに固定パーツを貼り付けます。強めに押し付けて数秒待ちます。
    <div align="center">

    ![こんな感じで当てて押し付けてください](img/IMG_7758.jpg)
    こんな感じで当てて押し付けてください
    </div>
4. 数秒経ったら治具を外します。写真のように回すように取ると上手く治具だけとれる気がします。
    <div align="center">

    ![こう外すと治具の方に固定パーツがついてきちゃうことが無い気がする（プラシーボがも）](img/IMG_7759.jpg)
    こう外すと治具の方に固定パーツがついてきちゃうことが無い気がする（プラシーボがも）

    ![固定パーツから革の端まですこし余白があるくらいになっているのが理想](img/IMG_7760.jpg)
    固定パーツから革の端まですこし余白があるくらいになっているのが理想
    </div>
5. 反対側も同様に固定パーツを接着します。
6. キーキャップをcutting_guideから取り外します。接着剤が乾くのを少し待ってからカッターの先を少し引っ掛けて取ったり、ULPキースイッチを片側だけ固定パーツに引っ掛ける取り外しやすいです。

以上で完成です。

## 終わりに

乾燥工程があるのでロングスパンで作成することになると思います。私はクランプを8個用意して4サイクル（2×4=8日間）で作成しました。  
使用するモデルが異なるだけで、ホーミングキーも同じ方法で作成できます  
ULPの打鍵感問題に少しでも貢献出来たらうれしいです。分かりづらいところがあれば何らかの手段でご連絡いただければと思います。  
また、これをきっかけにレザークラフトに興味を持っていただけたら幸いです。
